Privacy Policy

Last updated: 06 August 2026

1. Overview

"nondual poster" is a personal automation that publishes the operator's own content to the operator's own social media accounts. It has no users other than its operator, no website analytics, no ads, and no tracking.

2. Data the app processes

The app processes only what is technically required to publish posts to the operator's own accounts:

— OAuth access tokens for the operator's connected accounts (Instagram, TikTok).
— The operator's basic account information returned by the platform APIs (such as account ID and display name).
— The media files and captions the operator has prepared for publishing.

3. What the app does NOT do

It does not collect, store, or share any personal data of third parties. It does not read other users' content, followers, or messages. It does not sell or transfer data to anyone.

4. Storage and security

Access tokens are stored as encrypted repository secrets on GitHub and are used only by the automated publishing workflow. Media and captions are stored in the project repository. No separate databases or servers are operated.

5. Data deletion

Authorization can be revoked at any time in the connected platform's settings (e.g. TikTok app permissions), which invalidates the stored tokens. Stored tokens are then deleted from the repository secrets.

6. Contact

Questions can be addressed via the associated account @nondual.normal or via the project repository.
